# 《通识局》

**12 域通识知识闯关 · 好友同步抢答对战**

每天 5 道题，检验你在 12 个知识领域上的常识库存；
再开一局**同步抢答**，和朋友当场比出高下。

`Next.js 14` · `React 18` · `TypeScript` · `Tailwind 3` · `SSE`

## 快速开始

**第 1 步 —— 装依赖**

```bash
npm install
```

**第 2 步 —— 起服务**

```bash
npm run dev
```

打开 <http://localhost:3000> 就能玩了。首次进入会让你选 1–3 个「本命领域」，
或者直接点「随缘开局」让系统当天替你决定。

**第 3 步 —— 每天回来**

每天 5 道题，3 分钟。答错的题会在之后的日子里**回来找你**。

### 和朋友联机

双击 **`play-online.bat`** —— 脚本会自动构建、启动服务、建立 cloudflared 隧道，
并把公网链接复制到剪贴板。把链接发给朋友，两人在对战页输入同一个房间码即可。

> 局域网内调试可用 `npm run dev:lan`（监听 `0.0.0.0`）。
> 部署细节见 [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)。

## 四个亮点

### 🌗 影子对手 —— 和昨天的自己同场竞速

不用注册、不用等排行榜。同一组领域下，系统记住你过去的最好成绩，
答题时把它画成一条**金色目标线**：「你还需要 12 分越过影子」。

对手永远公平，因为对手就是你自己。

### 🎖️ 通识段位 —— 六段可见的成长线

见习 → 入门 → 通识 → 博闻 → 渊博 → 睿哲。

段位由你的**生涯累计**算出（答对题数、完成局数、星级、触及的知识点、连击、连续天数），
每 8 天左右升一段，三个月摸到顶。

### 🎲 盲盒轮转 —— 每天两个意料之外的领域

只固定 1 个本命，另外 2 个由日期决定、当天全网一致、**明天换新**。

给那些知道自己知识面窄的人 —— 通识的前提是敢走出舒适区。

### 🤝 同题 PK —— 同一个码，同一份题

两个人输入同一个 4–6 位 PK 码，各自本地跑同一份纯函数，
拿到**完全相同**的 5 道题。各自作答，最后用带 PK 码的成绩卡逐格对账。

没有服务器撮合，没有账号注册 —— 题目由你手机上的纯函数算出来。

## 玩法一览

| 玩法 | 说明 |
|---|---|
| **每日挑战** | 5 道题，难度曲线 `1→1→2→2→3`，末位是强制换域的**彩蛋题**。限时 30/25/20 秒。 |
| **知识链** | 跨域连续答对会点亮一条轨道，倍率最高 ×1.2。**对手抢先答对不算你失误**，连击保持。 |
| **同步抢答 duel** | 两人同一道题、同一倒计时，每题只有一次提交机会，先答对者独占分值。 |
| **同题 PK** | 同一个 PK 码 = 同一份题。各自跑、各自比，成绩卡逐格对账。 |
| **错题本** | 答错的题按 `1/3/7/15/30` 天间隔回来找你，**连对 2 次**才算毕业。 |
| **知识星图** | 12 域雷达图，一眼看出你在哪一块有洞。 |
| **战绩** | 最近 30 场 + 分数趋势 + 生涯累计。 |

**三种领域模式**（在选域页切换）：**本命模式**（固定 1–3 个）·
**盲盒轮转**（1 本命 + 2 每日盲盒）· **随缘开局**（每天由日期决定 3 个，全网同题）。

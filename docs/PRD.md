## 1. 一句话定位

**《通识局》是一款 12 域通识知识闯关游戏**：每天用 5 道题检验你在「游戏 / 动漫 / 科技 / 编程 / 生活 / 历史 / 汽车 / 手机 / 电影 / 科学 / 语文 / 地理」上的常识库存，
同时提供一个**同步抢答**的好友对战模式，把「你到底知道多少」变成可以当场比出来的对抗。

**它不是**又一个「无限答题流」的 App。区别在于三件事：

1. **每天的题全网一样** —— 同样的日期、同样的领域组合，题目与顺序在全世界完全一致，结果天然可比、可分享；
2. **题是有解析的知识密度载体**，不是纯娱乐的脑筋急转弯；
3. **错题会回来找你** —— 答错的题按间隔重复出现，连续答对两次才算「毕业」。

## 4. 三条产品线

### 4.1 每日挑战（Daily Challenge）—— 无状态、确定性、跨天 streak

**核心机制**：

```
题集 = f(daySeed, domains, count)
daySeed = hashSeed("daily:" + dateKey + ":" + canonicalDomains(domains).join(","))
```

`dateKey` 按 **Asia/Shanghai** 计算（`YYYY-MM-DD`），跨零点自动换题。
客户端与服务端跑**同一份** `lib/engine/daily.ts`，因此：

- 同一天 + 同一组领域 → **全网同一份题**（同题同序同难度曲线）；
- 领域按**集合**处理（`canonicalDomains()` 先排序）—— 选同一组领域的两个人，
  哪怕点选顺序不同，拿到的题也完全一致；
- 每日挑战**不需要任何服务端状态** → 可以部署到任意 Serverless，随时扩容；
- 换领域会重算题集（当天锁定后不再变），所以「先选域再开局」的顺序很重要。

**一轮 5 题**，难度曲线 `1 → 1 → 2 → 2 → 3`，末位为**彩蛋题**（强制换域，制造节奏变化）。

**计分公式**：

```
base   = { 难度1: 10, 难度2: 20, 难度3: 30 }
speed  = clamp(1 - elapsed / limit, 0, 1) * 0.5 + 0.5     // 0.5 ~ 1.0
blitz  = elapsed <= limit / 3 ? 1.2 : 1.0                  // 秒答加成
points = round(base * speed * blitz * comboMultiplier)
```

限时随难度递减：难度 1 = 30s，难度 2 = 25s，难度 3 = 20s。

**星级**：≥60% 满分 → ★★★；≥35% → ★★；其余 ★。

**跨天 streak**：每天完成一次即 +1，断签归零，历史最长单独记录（存 localStorage）。

### 4.2 同步抢答 duel —— 服务端权威计时 + SSE 实时

**玩法**：双方看到**同一道题、同一倒计时**。每人每题**只有一次提交机会**：

- 答对且**先于对手** → 独占该题分值，对手 0 分；
- 答错 → 立即锁定 0 分，本回合结束；
- 双方都答错或都没答 → 本回合无人得分。

**跨域连击（纯正向激励）**：

| 情况 | 连击变化 |
|---|---|
| 跨域抢先答对 | **+1** |
| 同域抢先答对 | 不变（不奖不罚） |
| 答错 | **归零** |
| 超时未答 | **归零** |
| **对手抢先答对** | **不变**（这不算你失误） |

倍率曲线：`0-1 → ×1.0`，`2-3 → ×1.05`，`4-5 → ×1.1`，`6+ → ×1.2`（封顶，避免滚雪球）。

**服务端权威**：计时、答案判定、回合推进、胜负判定**全部在服务端**。
客户端只提交答案，从不上报用时（`elapsed` 由服务端按收到时刻计算），
提交体中的未知字段会被 Zod 剥离。

**实时通道**：SSE（`/api/rooms/[code]/stream`）。

| 机制 | 参数 | 原因 |
|---|---|---|
| 心跳 | 25s | 保活中间代理，顺带在写失败时兜底清理 |
| 主动轮换 | 100s | 在平台 120s 硬杀前优雅关闭，把「平台硬杀」变成「清理必然执行」 |
| 僵尸回收 | 130s 判超龄 | 平台掐断后 `cancel()` 不保证触发，残留会占满配额导致「重连永远 429」 |

**相位机**：`lobby → countdown → question → feedback → (下一回合) → finished`。
推进采用「**惰性 + 定时器**」双保险 —— `syncRoomPhase()` 在读快照 / 提交答案 / 定时器回调三处调用，
Serverless 定时器丢失也能靠下一次调用收敛。

**凭证纪律**（安全红线）：

- `playerId` 只在**创建/加入房间的私有响应**里下发给本人；
- 快照与广播中 `players[].id` **一律脱敏**，对外一律用 **slot 索引**（`0` = 房主，`1` = 访客）；
- `RoomState.questions` **只存元数据**，答案与解析在结算时才下发。

### 4.3 知识图谱 · 错题重逢 —— 长期留存

**错题间隔重逢**（SM-2 简化版）：

- 间隔序列：`1 → 3 → 7 → 15 → 30` 天；
- 答错 → 连击归零、间隔重置到第 1 级、难度因子下调；
- 答对 → 连击 +1、间隔推进到下一级；
- **连续答对 2 次 → 毕业**（从错题队列移出）。

**知识星图**（`/map`）：12 域环形布局，每个 topic 用实心点表示掌握星级，
一眼看出「我在哪一块有洞」。

**战绩**（`/history`）：最近 30 场记录（每日挑战与对战），含得分、正确率、星级、最高连击。

**全部本地存储**：档案、错题本、熟练度、战绩、streak 都在 localStorage，不做账号体系。

| `/duel` | 对战大厅：创建房间 / 输入房间码加入 |

| `/map` | 知识星图 |
| `/history` | 战绩 |

**「随缘开局」**：按当日种子确定性地随机 3 个已上线领域 —— **全网同一天结果一致**。
首次可免费重抽 1 次（重抽后当天不再变）。

**成绩卡**：Canvas 生成 1200×630 PNG，含星级、得分、正确率、最高连击、日期与领域，一键下载分享。

## 6. AI 出题（特色但受限）

**定位**：内容补充工具，**不是**每日挑战的题源。

- 支持 OpenAI 兼容 API（`AI_API_BASE` / `AI_API_KEY` / `AI_MODEL`）与 Ollama；
- 未配置 provider 时接口直接返回 503，主链路完全不受影响；
- 生成结果过 **10 步校验链**：JSON 可解析 → 字段齐全 → domain/topic 命中白名单 → 难度合法 →
  答案命中选项 → 无歧义句式 → 解析长度达标 → 指纹去重 → 近似去重（Jaccard > 0.85）→ 敏感词过滤；
- 通过校验的题目只进**待审池**（`status: 'pending'`），人工抽检后才转正式题库；
- **AI 题永不参与每日挑战** —— 每日挑战必须可复现、可排行。

**变体模式**：对错题本里的题生成「同 topic 不同问法」的变体题，`variantOf` 指向原题 id。

## 7. 部署形态（双轨）

| 轨道 | 承载 | 平台 | 状态性 |
|---|---|---|---|
| **云轨** | 每日挑战、错题本、星图、战绩 | EdgeOne Pages（Node Functions） | 完全无状态 |
| **本地轨** | 同步抢答 duel | `play-online.bat` + cloudflared 隧道 | 房间态在进程内存 |

duel **明确不部署到 Serverless**：多实例内存不共享会导致房间状态撕裂。
详见 [`docs/DEPLOYMENT.md`](DEPLOYMENT.md)。

---

## 8. 技术约束（硬性）

- 依赖仅限 `zod` / `zustand` / `nanoid` / `lucide-react`；
- **PRNG、题库、计分、日期全部自实现**，不引入游戏/随机/日期库；
- 答案以**选项文本**存储而非 A/B/C/D 字母（客户端可能对选项排序，字母会失效）；
- 多选题答案入库时按**原始字符串字典序**排序，比较时按**归一化后**排序（两套顺序分开）；
- `edgeone.json` 的 `nodeFunctionsConfig.maxDuration = 120` **必须保留**，CI 会检查；
- 测试 glob 用**单星** `__tests__/*.test.ts`（双星在 Linux CI 会假绿灯）。
